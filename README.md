## Bot simples de clima para o Telegram
## 🚀 Como rodar este projeto na sua máquina

Para usar este bot, você precisará de suas próprias chaves de API do Telegram e do OpenWeatherMap.

1. Faça o clone (download) deste repositório.
2. Instale as bibliotecas necessárias rodando o comando:
   `pip install -r requirements.txt`
3. Renomeie o arquivo `.env.example` para `.env`.
4. Abra o arquivo `.env` recém-renomeado e substitua os textos falsos pelas suas próprias chaves de acesso.
5. Execute o arquivo principal:
   `python bot_clima.py`
